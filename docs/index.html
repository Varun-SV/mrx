04 / Make it yours

            
Your cast. Your configuration.

            

              Pair a local reasoner with an API executor. Or keep both local. The role stays the
              same; the model is your choice.
            

            
    
              
  • 
                01
                
    
                  
    Give each model a role
    
                  
    Choose provider, model, temperature, and token limit independently.
    
                
    
              
    • 
              
  • 
                02
                
    
                  
    Pick the interaction
    
                  
    Think then answer, plan then execute, or route each message yourself.
    
                
    
              
    • 
              
  • 
                03
                
    
                  
    Keep the conversation
    
                  
    Enable SQLite session history and resume a session from your terminal.
    
                
    
              
    • 
            

            Explore every config option →
          

          

            

              mrx.config.yamlLOCAL + API EXAMPLE
            

            
# Different strengths. One session.
default_mode: think_then_answer
session_memory: true

models:
  reasoner:
    provider: ollama
    model: qwen3:14b
    temperature: 0.6

  executor:
    provider: openai
    model: gpt-4o-mini
    temperature: 0.7

display:
  stream: true
  show_reasoning: false

            

              Set the executor provider’s API key in your environment. Model names shown are
              examples, not recommendations.
            

          

        

      


      
      

        

          

            
05 / Bring your models

            
Your next session has more possibilities.

            

              Start with Ollama. Add your own cast when you’re ready.
            

          

          

            

              01
              
Prepare your local models

              

                Install Node.js 22.12+ and Ollama. With Ollama running, pull the default models:
              

              
ollama pull qwen3:8b
ollama pull llama3.1:8b

            

            

              02
              
Install. Then ask.

              
No MRX config file needed for the defaults. Both roles start with Ollama.

              
              
mrx ask "explain recursion"
